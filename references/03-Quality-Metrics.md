## 一、AI词汇密度

### 定义
AI词汇密度是指文本中AI高频词汇出现的频率，反映文本的AI痕迹程度。

### 计算方法

**公式**：
```
AI词汇密度(‰) = AI词汇命中次数 / 总字数 × 1000
```

命中词表见 `scripts/ai_taste.py` 的 `AI_WORDS`（首先/其次/最后/综上所述/值得注意的是/赋能/闭环/抓手/深度融合/助力/生态/进一步/奠定坚实基础…；一个词只计一遍，不按出现次数累加）。

**示例**（脚本实测）：
- 文本总字数：115 字，命中 9 个词
- 密度 = 9 / 115 × 1000 ≈ 78.26‰

### 评估标准

| AI词汇密度 | 等级 | 说明 |
|-----------|------|------|
| < 2‰ | 优秀 | 无明显AI词汇痕迹 |
| 2-10‰ | 中等 | 有一定AI词汇痕迹，建议优化 |
| > 10‰ | 较差 | AI词汇痕迹明显，需要重点优化 |

> 阈值由旧版 2/5‰ 放宽到 2/10‰：实测一篇正常改写的中文 1000 字里出现 3-5 个"进一步/维度"仍是人写的，5‰ 卡太死会误伤。

### 改进目标
- 目标值：< 2‰
- 优化方法：替换AI高频词汇为真人表达

## 二、句子节奏（标准差 + 变异系数）

### 定义
句长变化程度反映节奏。这里给两个数：**总体标准差**（绝对值，随文本长度变化）和**变异系数 CV = 标准差 / 平均句长**（无量纲，可跨文本比较）。

### 计算方法

1. 按 `。！？；` 和换行切句
2. 统计每句字数
3. 平均句长 μ、总体标准差 σ = √(Σ(x-μ)²/n)
4. 变异系数 CV = σ / μ

**示例**（脚本实测，改写前 vs 改写后）：

| | 句数 | 平均句长 | 标准差 σ | 变异系数 CV |
|---|---|---|---|---|
| 改写前 | 3 | 37.3 | 14.66 | 0.39 |
| 改写后 | 4 | 17.2 | 3.83 | 0.22 |

**注意方向**：改写后 σ 从 14.66 掉到 3.83，这是**正常的**——口语化改写会把长句拆成短句，句子自然变整齐。旧版把"σ 越大越好、>10 才优秀"当判据是反的，长句堆叠的 AI 腔反而能刷出高分。

### 评估标准（仅对 ≥6 句的文本生效）

| 变异系数 CV | 等级 | 说明 |
|-----------|------|------|
| 0.4-0.9 | 优秀 | 长短句交错，节奏自然 |
| 0.25-0.4 | 中等 | 有变化，可再打磨 |
| < 0.25 或 > 0.9 | 注意 | 过于整齐 / 过于跳跃 |

句数 < 6 时脚本直接给中性 60 分，不参与判断（几个短句的 CV 没有统计意义）。

### 改进目标
- CV 落在 0.4-0.9 之间；**同时不要靠堆长句来拉高 σ**

## 三、真人感评分

### 定义
真人感评分反映文本读起来像真人写作的程度，由 AI 词汇密度分和句子节奏分加权，命中否定式排比扣分。

### 计算方法

```
密度分 D：长文本 D = clamp(100 - 7×密度‰, 30, 100)
         短文本(<300字) D = clamp(100 - 25×命中年词数, 30, 100)
节奏分 R：句数<6 → 60；否则 clamp(30 + (CV-0.2)/0.6×70, 30, 100)
真人感 = clamp(0.6×D + 0.4×R - 5×否定式排比数, 0, 100)
```

**示例**（脚本实测，案例 1 公众号文章）：

| | 密度‰ | 真人感 |
|---|---|---|
| 改写前 | 10.99 | 69.0 |
| 改写后 | 0.0 | 84.0 |

> 旧版公式 `30 + 70×(1 - 密度/10)` 在密度 21.98‰ 时会算出 **-53.8 分**，负分无意义；v2 一律 clamp 到 [0,100]。

### 评估标准

| 真人感评分 | 等级 | 说明 |
|-----------|------|------|
| > 80分 | 优秀 | 读起来像真人写的 |
| 60-80分 | 中等 | 有一定AI痕迹，可优化 |
| < 60分 | 较差 | AI痕迹明显，需要大改 |

### 改进目标
- 目标值：> 80分
- 优化方法：全面人性化改写（优先清 AI 词，其次调句长）

## 四、亲和力评分

### 定义
亲和力评分反映文本的温度和亲切感，同样由密度分与节奏分构成，但更看重节奏（口语文本句长更碎）。

### 计算方法

```
亲和力 = clamp(0.5×D + 0.5×R - 3×否定式排比数, 0, 100)   （单位：%，即百分制同值）
```

**示例**（脚本实测，案例 1）：

| | 改写前 | 改写后 |
|---|---|---|
| 亲和力 | 67.5 | 80.0 |

### 评估标准

| 亲和力评分 | 等级 | 说明 |
|-----------|------|------|
| > 80% | 优秀 | 亲切自然，有温度 |
| 60-80% | 中等 | 有亲和力，可进一步提升 |
| < 60% | 较差 | 冰冷生硬，需要优化 |

### 改进目标
- 目标值：> 80%
- 优化方法：拆长句、加第二人称、去掉书面套话

## 五、否定式排比结构

### 定义
否定式排比结构（如"不是...而是..."）是AI文本的典型特征，出现频率反映AI痕迹程度。

### 计算方法

**统计方法**：
- 统计"不是...而是..."出现次数
- 统计"不只是...更是..."出现次数
- 统计"与其说...不如说..."出现次数
- 统计"不是...就是..."出现次数
- 合计总次数

### 评估标准

| 出现次数 | 等级 | 说明 |
|---------|------|------|
| 0处 | 优秀 | 无AI惯用排比结构 |
| 1-2处 | 中等 | 有少量排比，可接受 |
| > 2处 | 较差 | 排比过多，需要优化 |

### 改进目标
- 目标值：0处
- 优化方法：用直接表达或举例说明替代

## 七、口径限制

1. **短文本（<300字）只看命中数，不看密度**：73 字里出现 1 个"进一步"就是 13.7‰，会被误判"较差"。
2. **句数 <6 时节奏分固定 60**：几个句子的 CV 没有统计意义，硬算会把"三个等长短句"判成呆板。
3. **口语文案往往会拉低 σ**：这是正常现象，别为了凑指标去堆长句。
4. **指标是尺子不是目标**：改得好不好最终看人读起来顺不顺，脚本只保证前后两次测量口径一致、可对比。

## 评估流程

### 标准流程
1. `python scripts/ai_taste.py 原文.md` 记下改写前各项
2. 改写
3. `python scripts/ai_taste.py --compare 原文.md 改写后.md` 得到前后变化
4. 把脚本输出填进对比表格
5. 总结核心优化点
6. 输出可视化效果说明

### 评估时机
- 完成人性化改写后立即评估
- 可作为改写效果的客观证明
- 帮助用户直观看到优化成果

---

## 注意事项

1. **指标仅供参考**：量化指标是辅助判断工具，不能完全代表真实效果
2. **综合判断**：需要结合人工阅读感受进行综合判断
3. **场景适配**：不同场景对指标的要求可能不同
4. **持续优化**：根据评估结果持续调整改写策略
5. **合规声明**：所有评估报告必须包含完整的免责声明
